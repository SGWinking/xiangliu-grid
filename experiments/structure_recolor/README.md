# 六图结构底稿重着色实验

这是与正式 Xiangliu Grid 流程隔离的实验。它读取 `R01–R02 × C07–C09` 六张图，不写回输入目录。

本轮指定 `R01_C09` 为标准色彩图，这是用户在前序试验中明确指定的色彩基准，不代表文物原始色彩证据。

运行：

```powershell
python experiments/structure_recolor/run_six_tile_pilot.py --source "D:\六张图所在目录" --output "D:\实验输出"
```

输出到 `validation/structure_recolor_pilot/`：原图总览、结构底稿、联合明度底稿、重着色结果、三联对比和接缝报告。

## 本轮实验结论

- 连续低频明度场降低了部分大接缝：三条亮度差由 `0.066→0.009`、`0.024→0.008`、`0.030→0.011`。
- 但 7 条接缝并未总体变好：处理前为黄 5、红 2，处理后为黄 4、红 3、绿 0；`R02_C08→R02_C09` 从黄色退化为红色。另有三条接缝的颜色或亮度指标回退。
- 结构底稿与统一色谱重着色不会改变图块几何，线条高频层得到保留。
- 用户标记的水纹硬边仍然可见。该区域两侧的灰阶底色、线条密度和局部对比本身不同，已经超出纯调色能解决的范围。
- 验收规则要求不能新增红缝。当前结果不满足。因此它最多作为调色前处理，不能单独替代接缝结构融合，暂不接入 48 张正式流程。
